# La Bütique

Site parodique (une page) du premier cöncept-störe éphémère-sédentaire basé sur le share-care et le rebranding.

- `index.html` : la page
- `assets/style.css` : le style (brutaliste)
- `assets/script.js` : panier, agenda, pop-up cookies, liste d'attente

Aucune étape de build : déposer le dossier sur Netlify (le `netlify.toml` publie la racine).
Pour tester en local : `python3 -m http.server` puis http://localhost:8000
